# Screenshots

Add the following screenshots to this folder:

1. **frontend-ui.png** - Frontend application interface
2. **backend-response.png** - Backend API response 
3. **docker-containers.png** - Running Docker containers
4. **jenkins-pipeline.png** - Jenkins CI/CD pipeline
5. **health-check.png** - Health check endpoint response

## How to take screenshots:

### Frontend UI:
- Open http://localhost:8080 in browser
- Take screenshot of the application interface
- Click "Check Backend" button and take another screenshot

### Backend API:
- Use Postman or browser to test http://localhost:3000/api/hello
- Take screenshot of JSON response

### Docker Containers:
- Run `docker-compose ps` command
- Take screenshot of running containers

### Jenkins Pipeline:
- Take screenshot of Jenkins pipeline execution
- Show build stages and status
